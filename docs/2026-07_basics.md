# Grundlegende Regeln und Aufbau

## Spiele

### Spiel 1

- Vogelname wird vom System vorgelesen
- Vier Bilder stehen zur Auswahl und man muss das richtige Bild anklicken
- 10 Bilder pro Runde, am Ende gibt's eine Punktzahl

### Spiel 2

- Wie Spiel 1, aber es wird per Tap ein Vogellaut abgespielt.

### Spiel 3

- Eine Feder wird dir gezeigt. Dann muss man sie dem Vogel zuordnen

### Spiel 4

- Bild vom Vogel zeigen, und dann muss man den Lebensraum antippen (Wald, Garten, ...)

## Allgemeines zur App

- Man braucht keinen Account, alles wird lokal gespeichert
- Es gibt mehrere lokale Profile
- Man wählt sich einen Avatar aus vorgefertigten Bildern, die Johanna cool findet
- Dem Profil wird ein Namen gegeben. Auch das wird lokal gespeichert
- Es gibt eine Übersicht der verschiedenen Spiele, die man auswählen kann
- Allgemeine Statistiken werden angezeigt über die gespielten Spiele und die erreichten Punkte
- Es gibt ein lokales Leaderboard
- Es gibt Rankings, man beginnt als Kohlmeise und steigt dann auf
- Es gibt keine Begrenzung von Spielen
- Es gibt die Möglichkeit in den Einstellungen eine maximale Spieldauer einzustellen. Die Einstellung ist mit einem Passwort oder FaceID geschützt.
- Wenn möglich kommen die Bilder aus einem öffentlichen und CC Bereich (wir nennen auch die Namen und geben die Lizenz an). Wir haben keine Gewinnabsichten mit der App.
- Es soll für iPads und iPhones entwickelt werden.
- Es soll eine OpenSource-Anwendung sein
