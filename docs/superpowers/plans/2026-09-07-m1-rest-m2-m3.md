## Working mode

- Every task lives in its own git worktree on a branch from `main`, named as in the task header, and ends in a PR that closes its issue with `Closes #N`. No stacking. Nobody self-merges.
- Implementation by Opus agents, exploration by Sonnet or Haiku. The coordinating session does not implement.
- Before opening a PR: `mise run check` green, output seen. Component PRs additionally show a rendered preview (screenshot in the PR).
- After every larger step and before every PR: run `/simplify` on the change, then `/code-review` with a Sonnet reviewer, and act on the findings. The PR text names what the review found and what was done about it (Christian, 2026-09-07).
- Language: code, comments, commits, PR texts in English. Product strings only through `Localizable.xcstrings`, in German.
- `design/` and `screens/` are read-only reference.
- Touch targets never below 64 pt; `correct` is olive, `retry` is sun yellow. Never red, never an X.
- Components carry no product strings. Any visible text (`FeedbackBanner`, `RewardSticker`, `SettingRow` labels) is a parameter; the only String Catalog stays in the app target. No second `Localizable.xcstrings` in a package.
- The three package placeholder files (`ZilpZalpCore.swift`, `ZilpZalpData.swift`, `ZilpZalpUI.swift`) keep their stale doc comments until the wave is over. Several parallel PRs land in each package; whoever "fixes" the comment causes the next merge conflict. One cleanup commit at the end.

**Reviewer capacity is the bottleneck.** Wave 1 is nine PRs for one reviewer on one self-hosted runner. Wave 1a is small and logic-heavy, wave 1b is preview-heavy; both can start at once. If that is too much, Christian says so and 1b waits for 1a.

## Shared contracts

These are fixed here so that parallel tasks do not drift apart.

### Pack manifest

One manifest per pack at `data/packs/<pack-id>/manifest.json`, media beside it. The gate (`tools/license_gate.py`) resolves `file` relative to the manifest's directory, so manifest and media must sit together.

```json
{
  "id": "basis",
  "title": "Unsere ersten Vögel",
  "birds": [
    {
      "id": "amsel",
      "name": "Amsel",
      "scientificName": "Turdus merula",
      "taxonID": 12716,
      "article": "die",
      "pronunciation": null,
      "photo": {
        "file": "photos/amsel.png",
        "sha256": "…",
        "license": "CC-BY-4.0",
        "attribution": "Alexis Tinker-Tsavalas",
        "sourceURL": "https://www.inaturalist.org/observations/20490738",
        "retrieved": "2026-08-01"
      },
      "call": null
    }
  ]
}
```

- `license` raw values are exactly `CC0-1.0`, `CC-BY-4.0`, `CC-BY-SA-4.0` — the strings the gate already enforces. The Swift enum uses the same raw values; an unknown value is a decoding error, and that is tested.
- `pronunciation` is an optional phonetic override for `AVSpeechSynthesizer` (#24 expects trouble with "Zilpzalp" and "Hausrotschwanz"). Reserved now because adding it later would be a schema bump.
- `call` is optional and `null` until a freely licensed recording exists.
- `retrieved` is an ISO date string, required.
- **Not in the manifest:** `bundled` (the catalog knows where it loaded a pack from) and `downloadSize` (lives only in `packs/index.json`, #50).
- `taxonID` values come from the iNaturalist API at curation time. Never guessed.
- The `title` is product content. The base pack title above is a placeholder for Johanna to confirm.

### Core species abstraction

`ZilpZalpCore` cannot import `Bird` from `ZilpZalpData`. Core exposes

```swift
public struct QuizSpecies: Hashable, Sendable {
    public let id: String      // "amsel"
    public let genus: String   // "Turdus" — first word of scientificName
}
```

The app maps `Bird` → `QuizSpecies`. Distractor distinctness (#22, "not three tits") is decided on `genus` alone.

Ranks are stable identifiers in Core (`Rank.kohlmeise` … `.wiedehopf`) with star thresholds 0/25/60/100/150/220/300/400. Their German display names live in the String Catalog, not in Core — Core holds no product strings.

### Licence identifiers in Swift

```swift
public enum License: String, Codable, Sendable {
    case cc0 = "CC0-1.0"
    case ccBy = "CC-BY-4.0"
    case ccBySa = "CC-BY-SA-4.0"
}
```

**Done when** `mise run check` is green and no `Font.custom(_:size:)` call remains in `ZilpZalpUI`.

### Task 2 — Pack and species schema as Codable models (#13)

**Branch:** `feat/pack-schema`. **PR:** `Closes #13`.

In `ZilpZalpData`: `Pack`, `Bird`, `MediaAsset`, `License` exactly as in *Shared contracts*. Plus `PackManifest` decoding from `Data` with a single `JSONDecoder` configuration (ISO dates as strings, no snake-case games).

Tests, Swift Testing: a full manifest round-trips; a bird without `call` decodes; a missing required field fails with the field named; an unknown licence string fails; `retrieved` must parse as a date. Valid fixtures live under `Tests/ZilpZalpDataTests/Fixtures/valid/` and are declared as test-target resources. The invalid cases are inline JSON literals in the test file, not files — the licence gate would rightly reject them.

**Not in this task:** `PackCatalog`, `PackDownloader`, `ProfileStore`. Nothing touches the file system.

**Done when** `mise run test` is green and the valid fixtures also pass `python tools/license_gate.py packages/ZilpZalpData/Tests/ZilpZalpDataTests/Fixtures/valid` (prove it in the PR text).

### Task 3 — Round engine (#22)

**Branch:** `feat/round-engine`. **PR:** `Closes #22`.

In `ZilpZalpCore`: `Round` built from `[QuizSpecies]` with an injected `inout some RandomNumberGenerator`.

- 10 questions of 4 choices; each question has one answer and three distractors from the same species set
- No species is the answer twice per round while the pool allows it
- Distractors prefer a different `genus` than the answer; when the pool cannot provide three, fall back to same-genus but never duplicate a species within one question
- **Small-pool rule** (review finding 4): fewer than 10 eligible species keeps 10 questions and allows repeats, pushed as late in the round as possible; fewer than 4 species throws `RoundError.insufficientSpecies`
- Constants for question and choice count are parameters with defaults, not magic numbers

Tests with a seeded generator: pool sizes 3, 4, 9, 10, 25; determinism (same seed, same round); no repeats at 10+; repeats only in the tail at 4–9; distractor genus rule; every choice set contains the answer exactly once.

### Task 4 — Scoring and rank ladder (#23)

**Branch:** `feat/scoring-ranks`. **PR:** `Closes #23`.

In `ZilpZalpCore`: `Scoring.stars(firstTryCorrect:)` — 3 at ≥ 9, 2 at ≥ 6, else 1. `Rank` as `CaseIterable` enum with `threshold` and `RankLadder.rank(forStars:)`, `RankLadder.next(after:)` returning the next rank and the stars still missing, `nil` at the top. Thresholds 0/25/60/100/150/220/300/400.

Tests at every boundary (0, 24, 25, 399, 400, 10 000) plus scoring at 5, 6, 8, 9, 10.

### Task 5 — Bootstrap the bundled base pack (#71)

**Branch:** `feat/base-pack-bootstrap`. **PR:** `Closes #71`, references #20 (which stays open for the high-resolution refetch and the calls). Needs Task 2 merged.

**Step 1, a 15-minute spike before anything else.** Three ways to get `data/packs/basis/` into `Bundle.module` of `ZilpZalpData`:

- (a) symlink `packages/ZilpZalpData/Sources/ZilpZalpData/Resources/Packs/basis → ../../../../../../data/packs/basis` and declare `.copy("Resources/Packs")` — preferred in #71
- (b) a committed copy, kept in sync by a small stdlib-only `tools/sync_bundled_packs.py` that `mise run check` runs and then fails on a dirty diff (5 MB duplicated in git, fully deterministic) — the fallback named in #71
- (c) the base pack lives only in the package's `Resources/Packs/basis/` and `mise run license-gate` runs the gate a second time with that directory as its argument (the gate takes exactly one root). Requires a sentence in AGENTS.md and the spec, because `data/packs/` would no longer hold the base pack

Try (a) first: `mise run test` (which runs `xcrun swift test` per package, the toolchain CI uses), `Bundle.module.url(forResource:)` in a test, then `mise run build`. If SwiftPM or `xcodebuild` does not follow the symlink, take (b). Choose (c) only if (b) turns out ugly. Record the outcome and the reason in the PR text and in Task 19.

**Step 2.** `data/packs/basis/manifest.json` per *Shared contracts* with the ten species: Amsel (die), Blaumeise (die), Buntspecht (der), Eisvogel (der), Hausrotschwanz (der), Kohlmeise (die), Rotkehlchen (das), Star (der), Wiedehopf (der), Zilpzalp (der). Photos copied unchanged from `design/assets/photos/*.png` into `data/packs/basis/photos/`, attribution and observation URLs from `design/assets/photos/CREDITS.md`, `sha256` computed from the copied file, `retrieved` = `2026-07-31` for all ten — CREDITS.md carries no date, so the commit date of the file (`baa5ab2`) is the best evidence of when the photos were fetched. `taxonID` looked up per species through `GET https://api.inaturalist.org/v1/taxa?q=<scientificName>&rank=species` at curation time; the PR lists the ten IDs with their source URLs. `call` is `null` for all ten. `pronunciation` is `null` for all ten; #24 fills it where needed.

**Step 3.** `PackCatalog` in `ZilpZalpData`, reading through `Bundle.module`:

```swift
public struct PackCatalog: Sendable {
    public let pack: Pack
    public static func bundled() throws -> PackCatalog
    public func photoURL(for bird: Bird) -> URL?   // nil when the file is missing
}
```

Tasks 10, 11 and 15 resolve photos only through `photoURL(for:)`. Downloaded packs (#33, M5) extend this type later; nothing here anticipates them. A test decodes the bundled manifest, resolves every bird's photo through `photoURL(for:)` and recomputes its SHA-256 against the manifest. This test is the Swift-side twin of the licence gate.

**Done when** `mise run check` prints `Licence gate passed: 10 media asset(s) in 1 manifest(s)`, `swift test` in `ZilpZalpData` is green, and `mise run build` succeeds.
