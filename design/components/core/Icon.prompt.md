Renders one Lucide glyph at a chunky stroke weight; use it inside Buttons, IconButtons and grown-up rows, never as a standalone kid-facing control.

```jsx
<Icon name="volume-2" size={40} color="var(--white)" />
```

Requires the Lucide UMD script on the page (`https://unpkg.com/lucide@latest/dist/umd/lucide.min.js`). Default `strokeWidth` is 2.5 to match the brand's illustrated outlines.
