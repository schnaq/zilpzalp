The one pressable text control — a chunky pill sitting on a solid colour ledge that squishes on press.

```jsx
<Button tone="primary" size="lg" iconRight="arrow-right">Weiter</Button>
```

Tones: `primary` (go/next), `accent` (one hoopoe-orange highlight per screen), `reward` (celebration screens), `quiet` (grown-up settings). Sizes `md|lg|xl` — never use `md` on a kid-facing screen. Labels are one or two words, sentence case, no punctuation.
